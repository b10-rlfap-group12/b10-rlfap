# Results

All files in this directory are produced by the scripts in `src/`. Re-run them to reproduce.

| File | Produced by | Contents |
|---|---|---|
| `results.csv` | `src/run.py` | One row per synthetic run: instance, size, seed, model, solver, status, time, objective, time limit, MiniZinc version |
| `raw/` | `src/run.py` | Full solver output for each synthetic run (all printed solutions and statistics) |
| `verification.csv` | `src/check_solutions.py` | Independent recomputation of every reported solution from the `.dzn` data |
| `summary.txt` | `src/analyze_results.py` | Status counts, timing, paired heuristic comparison, backend agreement on proven optima |
| `instance_statistics.csv` | `src/summarize_instances.py` | Size, constraint count, band, and duplex count of each synthetic instance |
| `celar_validation.csv` | `src/validate_celar.py` | Official CELAR runs: schema check, status, solve time, best objective, versions |
| `raw_celar/` | `src/validate_celar.py` | Full solver output for each official CELAR run |
| `plots/` | `src/plot.py` | Solve time (log scale) and objective versus number of radio links |

Synthetic data are generated by the project's own generator and are for controlled testing. Do not present them as field measurements.
